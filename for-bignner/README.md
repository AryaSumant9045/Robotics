# ROS 2 सीखने के लिए Free Resources

**ROS 2 (Robot Operating System 2) सीखने के लिए सबसे अच्छे मुफ्त रिसोर्स ये हैं:**

## 1. सबसे अच्छा फ्री ऑनलाइन बुक (Fully Free)

**ROS 2: Zero to Robot** — Pouya Mansournia

- पूरा प्रोजेक्ट-बेस्ड बुक (20 चैप्टर) — नोड से लेकर autonomous mobile robot, simulation, SLAM, Nav2, deployment तक।
- ROS 2 Jazzy पर आधारित।
- **Online पढ़ो:** https://pouya-mansournia.github.io/ros2-zero-to-robot/
- **GitHub:** https://github.com/Pouya-Mansournia/ros2-zero-to-robot

यह सबसे अच्छी मुफ्त प्रैक्टिकल बुक है beginners से advanced तक।

## 2. Official ROS 2 Documentation + Tutorials (सबसे authentic)

- **Tutorials (Beginner से Advanced):** https://docs.ros.org/en/jazzy/Tutorials.html
- Latest LTS version के लिए https://docs.ros.org/ चेक करो।

यहाँ से शुरू करो:

- Installation
- Nodes, Topics, Services, Actions
- Workspace, Packages
- Turtlesim practice

## 3. मुफ्त PDF Courses (Yahboom)

GitHub पर ROS 2 basic course के PDFs फ्री में उपलब्ध हैं:

https://github.com/YahboomTechnology/ROSMASTER-M1/tree/main/21.ROS2%20basic%20course

इसमें Introduction, Install, Workspace, Nodes, Topics, Services, Actions, Launch, URDF, Gazebo, TF2 आदि सबके PDFs हैं।

## शुरू कैसे करें (Recommended Path)

1. Official tutorials से शुरू करो (Turtlesim के साथ)।
2. फिर **ROS 2: Zero to Robot** बुक पढ़ो + code चलाओ।
3. Ubuntu 22.04/24.04 + ROS 2 Humble/Jazzy इंस्टॉल करो।
4. Python अच्छी तरह जान लो (C++ optional)।

ये सारे लिंक मुफ्त learning resources हैं। शुरू में कोई paid किताब खरीदने की जरूरत नहीं है।
